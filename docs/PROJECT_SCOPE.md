# Project scope

**Sol i Sòl** is an academic, team-built proof of concept developed as though responding to an agrivoltaic client's procurement brief.

## Main workstreams

1. Data assessment: explore missing and inconsistent readings, temporal aggregation and feature extraction.
2. Decision support: design an interpretable, multi-objective solar-panel angle recommendation policy.
3. Predictive modelling: compare regression approaches for approximating that policy.
4. Scenario exploration: generate synthetic environmental and agricultural conditions.
5. Interface: demonstrate recommendations, indicators, alerts and scenarios in a dashboard.
6. Delivery planning: produce a fictional commercial proposal with schedule, budget, risk register and responsibilities.

## Out of scope

Live hardware integration, operational roll-out, sensor validation, measured energy-yield improvement, or verified crop-yield uplift.

## Team credit

Developed collaboratively for university coursework. The repository describes the team's output without attributing individual code sections.
